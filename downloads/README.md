# Download GharKiraya for Android

[Download the Android APK](https://github.com/anup-bihari/GharKiraya/raw/refs/heads/android-development/downloads/GharKiraya-debug.apk)

Open the link on your Android phone, open the downloaded file, allow installation from your browser if prompted, and tap **Install**.

Requires Android 8.0 or newer and an internet connection. This is a debug-signed development build of the website-backed app, not a Play Store release. The APK was built from commit `e96b0d6`. The SHA-256 checksum is in `SHA256SUMS` (run verification from the repository root). Rebuild and replace this APK when the Android source changes.
